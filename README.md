# My Portfolio

This is a portfolio website built with React, Vite, and Tailwind CSS. It showcases my projects, skills, and provides a way for visitors to contact me.

## Features

*   **Responsive Design:** The website is fully responsive and works on all devices.
*   **Dark Mode:** A dark mode option is available for a better user experience in low-light environments.
*   **Animations:** The website uses Framer Motion to create smooth and engaging animations.
*   **Project Showcase:** A dedicated section to display my projects with links to live demos and source code.
*   **Skills Section:** A section to list my skills and their proficiency levels.
*   **Contact Form:** A functional contact form for visitors to get in touch with me.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

*   Node.js and npm installed on your machine.

### Installation

1.  Clone the repo

    ```sh
    git clone https://github.com/your_username/my-portfolio.git
    ```
2.  Install NPM packages

    ```sh
    npm install
    ```

### Usage

To start the development server, run the following command:

```sh
npm run dev
```

This will start the development server at `http://localhost:5173`.

To build the project for production, run the following command:

```sh
npm run build
```

This will create a `dist` folder with the production-ready files.

## Dependencies
